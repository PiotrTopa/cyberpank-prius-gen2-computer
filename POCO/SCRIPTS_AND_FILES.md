# Scripts and files — POCO F1 (custom additions)

Every file added or changed on top of stock postmarketOS. The overlay is mirrored 1:1
under [rootfs/](rootfs/) (plus [dts/pmi8998-usb-vbus.dtso](dts/pmi8998-usb-vbus.dtso))
and installed with `sync.sh` / `provision.sh` ([PROVISIONING.md](PROVISIONING.md)).

## Flags (`/etc/prius/`, seeded by `provision.sh` only if missing)

| File | Values | Seed | Read by |
|---|---|---|---|
| `power-mode` | `low` \| `full` | `full` | `prius-power` ([POWER.md](POWER.md)) |
| `wifi-mode` | `client` \| `ap` \| `off` | `ap` | `prius-wifi` |
| `usb-mode` | `host` \| `device` | `host` | `prius-usb` |
| `wifi-grace` | systemd time span | `20min` | `prius-power` (Wi-Fi suspend after key-off) |
| `netwatch-grace` | systemd time span | `20min` | `prius-power` (netwatch arm after key-off) |
| `lifeline-fails` | integer ≥ 1 | `3` | `prius-lifeline` (misses at 30 s before the AP lifeline turns ON) |
| `lifeline-hold` | span (`600`, `90s`, `10min`, `1h`) | `10min` | `prius-lifeline` (uplink back this long → lifeline OFF) |
| `blank-display` | presence | absent | `prius-power` (opt-in DSI blanking) |
| `sim-pin` | PIN (root-only) | rendered from `secrets.env` | `prius-sim-unlock` |
| `backend.env` | `BACKEND_*` env | seeded by `provision.sh` | `prius-backend` |
| `backend-auth.env` | `BACKEND_AUTH_TOKEN=` (root 0600) | generated by `provision.sh` if absent; `prius-auth token new` | `prius-backend` ([docs/AUTH.md](../docs/AUTH.md)) |
| `satellites/` | `car.key`, `car.pub`, `keychain.json` | `prius-satkey init` | backend, `prius-satkey` ([docs/SATELLITES.md](../docs/SATELLITES.md)) |

## Scripts (`/usr/local/sbin/`)

| Script | Usage | Purpose |
|---|---|---|
| `prius-backend` | `ensure-venv` \| `run` \| `status` | backend venv + launcher (`prius-backend.service`); config `/etc/prius/backend.env` |
| `prius-power` | `low` \| `full` \| `apply` \| `status` | CPU profiles, key-off timers, opt-in blanking ([POWER.md](POWER.md)) |
| `prius-blankd` | daemon | DRM modeset-off of the DSI pipeline (`prius-blank.service`) |
| `prius-wifi` | `client` \| `ap` \| `off` \| `apply` \| `suspend` \| `resume` \| `lifeline` \| `status` | Wi-Fi modes; `suspend`/`resume`/`lifeline` leave the flag; while the lifeline is ON `suspend` is a no-op and `off` keeps the AP; never touches WAN/VPN |
| `prius-lifeline` | `run` \| `tick` \| `status` \| `state` \| `simulate-down <s>` \| `simulate-clear` | AP lifeline: hub unreachable 3 checks → car AP up until the uplink has been back 10 min; never bounces links ([NETWORKING.md](NETWORKING.md#wi-fi-ap-lifeline-prius-lifeline)); state `/run/prius-lifeline/` |
| `prius-netwatch` | `once` \| `status` \| `check` | VPN-over-SIM watchdog, ACC-off only ([NETWORKING.md](NETWORKING.md)) |
| `prius-sim-unlock` | — | one-shot QMI PIN1 verify per boot |
| `prius-clock-fallback` | — | HTTPS `Date` clock step while NTP is unsynchronized; touches `/run/prius-clock-synced` |
| `prius-usb` | `host` \| `device` \| `status` `[--reboot]` | USB role via DTB `dr_mode` + `mkinitfs` |
| `prius-vbus` | `apply` \| `revert` \| `status` `[--reboot]` | PMI8998 VBUS regulator node ([ARCHITECTURE.md](ARCHITECTURE.md)) |
| `prius-dtb-patch` | `apply IN OUT` \| `check DTB` \| `check-live` \| `check-bootimg IMG` | the device-tree patch (USB host, VBUS, FT8719 touch) as one reproducible, fail-closed step ([docs/POCO_REBUILD.md](../docs/POCO_REBUILD.md) §1) |
| `prius-bootimg` | `build OUTDIR [DTB] [INITRAMFS]` \| `compare IMG` \| `dryrun` \| `hooktest` | boot.img built by the real boot-deploy into a scratch dir, never flashed; compared with the boot partition |
| `prius-dt-check` | `[status]` | DT patch present in the running DT, the boot partition and /boot? Flag `/run/prius-dt-check`; `prius-dt-check.service` at boot |
| `prius-usb-power` | `status` \| `locate` \| `cycle` \| `off` \| `on` `[TARGET]` | hub port power via `uhubctl -f` ([POWER.md](POWER.md#usb-hub-and-port-power)) |
| `prius-flash-powerbox` | `[FILE ...]` | powerbox firmware update over NDJSON via `pb_flash.py` (default main.py + boot.py + bean_rx.py + bean_tx.py); stops and restarts `prius-backend` ([powerbox/README.md](../powerbox/README.md#flashing-firmware)) |
| `prius-deploy-mfd` | `[--dry-run]` | rsync the frontend to the MFD Pi over `usb0`, install the Pi's timesyncd config (time from the phone), restart `mfd.service` (as root) |
| `prius-bled` | daemon | BLE satellite daemon on `hci0` (`prius-bled.service`, socket `/run/prius/bled.sock`) |
| `prius-auth` | `link [--host] [--ttl]` \| `hosts` \| `sessions` \| `revoke` \| `revoke-all` \| `token new [--stdout]` \| `status` | API access: one-time browser pairing links, sessions, token ([docs/AUTH.md](../docs/AUTH.md)); state `/var/lib/prius/auth` (root 0700) |
| `prius-auth-link` | `[--host] [--ttl]` | shorthand for `prius-auth link` |
| `prius-satkey` | `init` \| `list` \| `new` \| `sign` \| `add-rs485` \| `show` \| `revoke` \| `forget` \| `export-pub` | satellite keychain CLI |

## systemd units (`/etc/systemd/system/`)

| Unit | Type | Enabled | Purpose |
|---|---|---|---|
| `prius-backend.service` | simple | yes | backend; `prius.slice`, CPUWeight 1000, Nice −10, MemoryMax 512M |
| `prius.slice` | slice | — | `AllowedCPUs=3`, MemoryMax 640M |
| `roadsense.slice.d/`, `system.slice.d/`, `user.slice.d/` `50-prius-cpus.conf` | drop-ins | — | `AllowedCPUs=0-2,4-7` |
| `prius-power.service` / `.path` | oneshot / path | yes | apply `power-mode` at boot and on change |
| `prius-blank.service` | simple | no | `prius-blankd`; started by `prius-power` only with `blank-display` |
| `prius-wifi.service` / `.path` | oneshot / path | yes | apply `wifi-mode` at boot and on change |
| `prius-netwatch.service` / `.timer` | oneshot / timer | **never** | timer started by `prius-power` 20 min after key-off, stopped at key-on |
| `prius-lifeline.service` | simple (loop, `Restart=always`) | yes | uplink down ⇒ car AP up, every profile |
| `prius-sim-unlock.service` | oneshot | yes | SIM PIN over QMI |
| `prius-clock-fallback.service` / `.timer` | oneshot / timer | timer yes | 2 min after boot, every 5 min |
| `prius-bled.service` | simple | yes | BLE satellites |
| `prius-gnss-bridge.service` | simple | yes | head-unit GPS over ADB to the backend position API (`hu-gnss-bridge --post --quiet`, user `user`, owns the adb server); tools installed by `tools/headunit/install.sh` |
| `backlight-off.service` | oneshot | yes | backlight 0 at boot |
| `systemd-backlight@backlight:backlight.service` | — | masked | no backlight restore |
| `systemd-battery-check.service` | — | masked | phantom battery must not gate boot |
| transient `prius-wifi-suspend`, `prius-netwatch-arm` | timers | — | created by `prius-power low` (`systemd-run`) |
| `roadsense.target`, `roadsense-*.service` | — | target **not** enabled | installed by the roadsense repos; started by the backend |

## Inspection

systemctl list-unit-files | grep -E 'prius|backlight-off|roadsense'
cat /etc/prius/power-mode /etc/prius/wifi-mode /etc/prius/usb-mode
sudo prius-power status; sudo prius-wifi status; sudo prius-usb status; sudo prius-netwatch status
prius-lifeline status; journalctl -u prius-lifeline -n 20
nmcli -t -f NAME,DEVICE,STATE c show; sudo wg show wg-homelab; mmcli -m any
